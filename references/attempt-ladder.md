# 显著性尝试梯子

## 第 0 层：先判断是不是值得救

- 研究问题是否还成立
- 数据口径是否与新法律、新政策或新平台规则冲突
- 结果若成立是否带来明显伦理、法律或职业风险

如果这里已经不成立，先封存，不进入试显著。

## 第 1 层：变量诊断

1. 锁定 `x`
2. 锁定 `y`
3. 审核 `x`、`y` 的主定义与备选口径
4. 查覆盖、缺失、断点、异常值

## 第 2 层：基准识别

1. 跑最自然的基准回归
2. 先看方向，再看显著性
3. 记录样本量与核心单位数量

## 第 3 层：不改识别的调参

1. 对数/比例/强度/人均
2. 分母调整
3. 缩尾
4. 单位重缩放

## 第 4 层：识别附近的调参

1. 固定效应
2. 聚类层级
3. 交错 DID / 堆叠 DID
4. 事件窗口
5. 事件研究图与主回归对齐

## 第 5 层：控制变量

1. 低缺失控制先试
2. 经济含义清楚的控制再加
3. 完整全控制最后试
4. 每次都审计样本损失

## 第 6 层：停机

满足任一条就可以停：

- 方向稳定且显著性已够正文使用
- 方向稳定但始终不显著，且新增调参没有信息增量
- 只有极端窗口或异常小样本才显著
- 事件研究图与主回归长期不一致
- 题目本身已不适合继续推进
