# 苏格拉底式提问协议（完整清单）

> skill：`xianzhu-skill` v2.0.2  
> 用途：每一步之前先问的问题集；与 `SKILL.md` 的"标准工作流"段同步。
> 强度：**软纪律**（标 📝 推荐先问，不阻塞执行，鼓励留痕）。

---

## 为什么需要这份清单

跑规格搜索很容易陷入两种陷阱：

1. **机械套用**：每一步按文档操作，但忘了"为什么是这一步"。
2. **结果诱导**：为了得到某个方向 / 显著性，把每一步的解释都往那个方向拉。

苏格拉底式提问协议让使用者在每一步先回答"看起来很基础但经常被跳过"的问题：

- 帮助 AI（CC）**显式暴露自己的假设**，避免在没想清楚的前提下硬跑；
- 帮助使用者**主动梳理自己当前的认识**，避免跑完一长串规格才发现方向走错。

## 通用格式

每条提问都遵循三段式：

```text
Q. <问题>
   为什么：<跳过它会有什么风险>
   怎么答：<可以怎么回答；答到什么程度算"够">
   失败模式：<答错了 / 答不上来会导致什么结果>
```

## 推荐留痕位置

| 文档 | 留什么 |
|---|---|
| `沟通记录.md` | "我刚问了自己：…… 答：……"（每 Step 之前） |
| `output/审计/spec-log_<时间戳>.csv` | Q 列与 A 列 |
| `step0-audit.md` 的"决策记录"段 | Step 0 阶段的提问与回答 |
| Stata `.do` 文件注释 | 关键决策前的提问与回答 |

## Step 0 · 题目还能不能做

### Q1. 这个题目的研究问题本质上要回答什么？用一句话说清楚。
- 为什么：说不清楚 = 问题还没到"值不值得救"这一步，先回去问老师。
- 怎么答：用 1-2 句话讲清楚"x 对 y 的影响"或"机制 A 经由 B 影响 C"。
- 失败模式：进入规格搜索阶段但其实研究问题未明确 → 7 轮顺序白跑。

### Q2. 如果 Step 0 通过但你做不出显著，你打算怎么向老师 / 审稿人解释？
- 为什么：答不上来 = 你在做"为了显著而显著"的题目。
- 怎么答：能讲清楚"我会汇报方向、量级、样本量、稳健性范围，而不是 p 值"。
- 失败模式：全程只盯着 p 值，对方向和量级没预期 → 跑出来波动就慌。

### Q3. 当前数据 / 法律 / 平台是否有任何"已知危险信号"你还没查过？
- 为什么：跳过 L3 任意一项 = 已经在制造未来的返工。
- 怎么答：能列出 L3 各子项（政策 / 数据源 / 平台 / 法律 / 撤稿 / 制裁）的最近一次核查日期。
- 失败模式：项目跑到一半才发现数据已下线 / 法规已禁止 → 全部归档。

### Q4. 如果这个题目"做不出来"，你能接受的最坏结果是什么？
- 为什么：明确底线有助于后续停机决策。
- 怎么答：能讲清楚"至少能写一段机制讨论 / 描述性证据 / 政策评估"。
- 失败模式：把"做不出来"等同于"完全没用"→ 中途不肯停。

### Q5. 这一步的失败处置（封存 vs. 等用户回话）由谁决定？
- 为什么：L1/L2 直接封存、L3/L4 询问用户，处置权不在你手上。
- 怎么答：能讲清楚"如果我看到 L1 失败会写 STOP_step0_L1.md，不会回问用户"。
- 失败模式：L1 失败也回问用户 → 用户疲劳，下次真要问时反而被跳过。

### Q6. 这个题是不是 30 天内跑过 Step 0？如果是，结果还能复用吗？
- 为什么：复用旧结果省时间，但也要避免因数据 / 法律变化而误用。
- 怎么答：能讲清楚"复用 L1/L2 / 重跑 L3 / L4 视情况"。
- 失败模式：复用了旧 L3 结果，但中间法规改了 → 错的。

## Step 1 · 锁定研究问题与 x/y

### Q1. 你的 x 和 y 在经济理论上分别代表什么因果机制？
- 为什么：答不上来 = 你在做"为跑回归而跑回归"。
- 怎么答：用 1-2 句话讲清楚 x 怎么进入 y 的生产函数 / 决策函数。
- 失败模式：x/y 的经济含义变了但你没意识到 → 7 轮顺序全在变变量。

### Q2. 如果结果方向与你预期相反，你会怎么解释？这种反向解释你能辩护吗？
- 为什么：想不出反向解释 = 你可能在 p-hacking 期望方向。
- 怎么答：能讲出至少 1 个"如果出现相反结果，是因为 …… "的机制解释。
- 失败模式：跑出反向结果直接丢掉 / 不承认。

### Q3. x 和 y 是不是已经被老师 / 正文 / 目标文献明确？
- 为什么：不明确 = 还没到规格搜索，回到问题梳理阶段。
- 怎么答：能讲清楚"老师邮件 / 正文第 X 节 / 目标文献表 Y 第 Z 列"。
- 失败模式：用了一个新造的代理变量，但代理是否合适没文献支持 → v2.0.0 硬边界禁止。

### Q4. 如果 x 与 y 同时存在多个度量，你会选哪一个作为"主规格"？
- 为什么：选了之后再换 = 等于先入为主。
- 怎么答：能讲清楚"我选 X1 是因为它在文献里最常用 / 数据质量最高"。
- 失败模式：先跑了一个发现不显著，立刻换 X2 重跑 = 偷换变量。

### Q5. 你是否已经接受某个识别策略或基准模型？
- 为什么：识别策略变了 = 等于换了一道题。
- 怎么答：能讲清楚"我的识别是 DID / RD / IV / ... 基准模型是 ……"。
- 失败模式：跑规格时顺手换了识别策略 → 没法归因。

### Q6. 这一步你打算花多少时间？什么时候算"锁定"？
- 为什么：拖太久 = 在规格搜索阶段混入问题梳理。
- 怎么答：能讲清楚"Step 1 在 1-2 个工作日内完成"。
- 失败模式：Step 1 跑一周，问题还在改。

## Step 2 · 先审数据，不先审 p 值

### Q1. 这一步你打算试 x 还是试 y？为什么不是另一边？
- 为什么：答"两边都要试" = 你还没想清楚要诊断什么。
- 怎么答：能讲清楚"我先试 y 因为 y 口径不稳"或"我先试 x 因为 x 代理多"。
- 失败模式：两边同时试，跑完不知道哪个起作用了。

### Q2. 如果两边都要试，你打算先做哪一边？另一边的失败会改变这边的结论吗？
- 为什么：答不上来 = 没控制试错顺序的耦合。
- 怎么答：能讲清楚"两边独立 / 串联"以及"哪一边先做"。
- 失败模式：耦合效应没被察觉 → 误判变量重要性。

### Q3. 检查清单里（覆盖范围 / 缺失 / 时间断点 / 异常分母 / 口径突变 / 行政变化）哪一项最有可能吞掉你的结果？
- 为什么：没思考过 = 默认假设"数据没问题"，这是经验研究最大的坑。
- 怎么答：能列出 1-2 个最危险项并说明"我打算怎么排除"。
- 失败模式：跑出来发现数据有突变年，但事前没排除 → 全部规格都受影响。

### Q4. 你的样本是不是"主要样本"，还是"为了显著特意缩的小样本"？
- 为什么：默认小样本 = p-hacking 的常见路径。
- 怎么答：能讲清楚"我的主样本是 …… 排除规则是 …… 排除掉了 X% 观察"。
- 失败模式：跑了 5 个样本口径才得到"显著"，但正文只放最显著那一个。

### Q5. 这一步的产物是不是会让"原本的样本数 N"明显下降？
- 为什么：样本塌缩 = 后续统计功效下降。
- 怎么答：能讲清楚"清洗前 N=...，清洗后 N=...，缩了 X%"。
- 失败模式：清洗后剩 1/3 样本，结果靠这一小撮人。

### Q6. 这一步的产物有没有"人为干预"的痕迹？
- 为什么：经验研究最重要的可辩护性 = 清洗规则可复现。
- 怎么答：能讲清楚"清洗代码在 .do 文件 X 行，规则可复现"。
- 失败模式：手动改了几个值 / 删了几个观察但没留痕 → 审稿人质疑。

## Step 3 · 选择估计方法集合

### Q1. 你的识别策略要排除的核心混淆是什么？
- 为什么：答不上来 = 选方法等于"猜哪个 R² 高"。
- 怎么答：能讲清楚"我担心 X 混淆，方法是 Y 来排除"。
- 失败模式：跑了一堆方法，但方法与混淆不匹配。

### Q2. 选择的方法是否能识别这个混淆？还是你只是因为"它是当前默认方法"而选？
- 为什么：默认方法不等于合适方法。
- 怎么答：能讲清楚"我选 DID 是因为 …… ，不是因为我看了别人的论文"。
- 失败模式：别人用 DID 我也用 DID，但数据不支持 DID 假设。

### Q3. 你打算同时上几个方法？如果它们结果不一致，你会怎么选？
- 为什么：答不上来 = 你没想好怎么归因。
- 怎么答：能讲清楚"我会上 3 个：基准 / 稳健性 / 异质性，结果不一致时优先基准"。
- 失败模式：方法多了反而解释不了 → 审稿人问"你到底信哪一个"。

### Q4. 这一步选的方法是不是已经被同行用过？
- 为什么：陌生方法 = 解释成本高。
- 怎么答：能列出至少 1 篇"用了相同方法 + 相同数据"的文献。
- 失败模式：发明了一个新方法，但审稿人无法比对。

### Q5. 这一步的方法选择有没有"为了显著而选"的成分？
- 为什么：这是经验研究最隐蔽的 p-hacking。
- 怎么答：能讲清楚"我选这个方法是因为它识别 X 混淆，而不是因为它可能让 Y 显著"。
- 失败模式：跑完所有方法后才发现最显著那一个，但原因说不清。

### Q6. 这一步要不要预设一组"必跑"的稳健性规格？
- 为什么：必跑规格 = 哪怕主规格挂了也有一份能交差的结果。
- 怎么答：能列出至少 3 个稳健性规格（换 FE / 换聚类 / 换样本）。
- 失败模式：主规格挂了，再临时想稳健性 → 容易引向 p-hacking。

## Step 4 · 先试"识别不变"的调参

### Q1. 你选择的变换是否改变了 x / y 的经济含义？
- 为什么：改变了 = 这不是"识别不变"，你在偷换变量。
- 怎么答：能讲清楚"log(y) 让 y 的解释变成弹性，含义不变"。
- 失败模式：用 `asinh(y)` 跑出"显著"，但其实 y 的解释已经从"水平"变成"反双曲正弦"。

### Q2. 如果变换让结果"显著"了，但代价是经济含义变弱，你会选哪一个？
- 为什么：默认选"显著" = 已经在 p-hacking。
- 怎么答：能讲清楚"我会选解释优先 / 用原口径作为主规格"。
- 失败模式：跑了一圈只有变换口径显著 → 强行换口径当主规格。

### Q3. 这一步能不能保证：换了任何一种变换，研究问题不变？
- 为什么：不能 = 你在做"找替代指标"，而不是"识别不变调参"。
- 怎么答：能讲清楚"研究问题是 X → Y，所有变换都不改这个方向"。
- 失败模式：变换后 x 和 y 的关系从"A 导致 B"变成"A 引起 B 的代理"。

### Q4. 你的变换清单是不是被限定在 5-8 个以内？
- 为什么：变换多了 = 必有"恰好显著"的那个。
- 怎么答：能列出具体清单（log / asinh / winsor / 比例 / 人均 / 缩尾 / 离散化 / 分母重构）。
- 失败模式：临时增加新变换 → 等于在做"无限制搜索"。

### Q5. 你的缩尾 / winsor 比例是文献常用的还是你自创的？
- 为什么：自创比例 = 难以辩护。
- 怎么答：能讲清楚"我 winsor 在 1% 和 99%，这是文献 X 的常规做法"。
- 失败模式：跑了 0.5% / 1% / 5% / 10% 四档 winsor，只报显著那档。

### Q6. 你的分子 / 分母重构有没有经济学理由？
- 为什么：分母变了 = 结果的量纲变了。
- 怎么答：能讲清楚"分母从总资产改成净资产是因为 ……"。
- 失败模式：换了 4 种分母，挑了一个让结果显著的。

## Step 5 · 再试模型层面的调参

### Q1. 你的事件研究与主回归"绑在一起审"了吗？它们是一致的吗？
- 为什么：没审 = 你跳过了模型层最关键的一致性体检。
- 怎么答：能讲清楚"主回归显著、事件研究在事前为 0、事后为正，二者一致"。
- 失败模式：主回归显著、事件研究乱跳 → 选主回归当正文，事件研究藏着。

### Q2. 如果不一致，你会怎么解释这种不一致？还是会调整识别让它一致？
- 为什么：答"调识别让它一致" = 已经是事后合理化。
- 怎么答：能讲清楚"我会先解释 / 不能解释就停 / 不通过调整识别来强行一致"。
- 失败模式：事件研究预趋势显著（违反平行趋势），换个处理组让预趋势消失 → 偷换。

### Q3. 这一步聚类层级 / FE 结构 / 事件窗口的选择有没有"为了显著而选"的成分？
- 为什么：有 = 应该先回 Step 2 重审数据。
- 怎么答：能讲清楚"我选聚类在县层，因为这是处理变量的所在层"。
- 失败模式：跑了 5 个聚类层级，挑了一个。

### Q5. 你的 TWFE / 交错 DID / 堆叠 DID 选择是否与"处理时点异质性"匹配？
- 为什么：交错 DID 在异质处理时点下会有负权重问题。
- 怎么答：能讲清楚"我的处理时点是单一的 → TWFE 合适 / 处理时点异质 → 堆叠 DID"。
- 失败模式：处理时点异质但硬上 TWFE → 系数有偏。

### Q6. 你的事件窗口是不是被"为显著而缩"过？
- 为什么：窗口缩太短 = p-hacking 的经典套路。
- 怎么答：能讲清楚"我的窗口是 [-3, +5]，由政策时点决定，不是事后挑"。
- 失败模式：跑了 [-5,+5] / [-3,+3] / [-2,+2] / [-1,+1]，最后用 [-1,+1] 报显著。

## Step 5.5 · 先排查"样本问题"和"吸收问题"

### Q1. 加控制变量后样本缩了多少？缩的是哪些观察？
- 为什么：不清楚 = 你不知道结果变好是因为加对了控制，还是换了一批人。
- 怎么答：能讲清楚"加 X 后 N 从 1705 缩到 1623，缩的是缺 X 数据的观察"。
- 失败模式：缩了 30% 的样本，但正文里轻描淡写"样本略有减少"。

### Q2. 高维 FE 是否可能吸收了核心 x 的识别？
- 为什么：不知道 = 默认假设"没问题"，但默认假设是经验研究最大的坑。
- 怎么答：能讲清楚"我加了城市×年份 FE，x 在城市间无变化时被吸收"。
- 失败模式：核心 x 被吸收了，但 R² 还很高 → 没意识到。

### Q3. 这一步的目标是不是"先解释为什么之前不显著"，而不是"马上让结果显著"？
- 为什么：后者 = 顺序错了，先回 Step 5 而不是接着做 Step 6。
- 怎么答：能讲清楚"我现在是在诊断，不是在调优"。
- 失败模式：跳过诊断直接调优 → 把样本问题当模型问题处理。

### Q4. 这一步有没有写过"样本收缩诊断表"？
- 为什么：可辩护 = 必须能展示样本如何变化。
- 怎么答：能讲清楚"表 X 列出了每加一层控制变量样本怎么变"。
- 失败模式：正文只放最干净的样本口径，过程不展示。

### Q5. 你的 FE 是否包含"处理变量所在层级"的更高维 FE？
- 为什么：高维 FE 可能"过度吸收"识别。
- 怎么答：能讲清楚"我的处理在县层，所以 FE 最多到县×年份，不再往上了"。
- 失败模式：FE 一路加到城市×年份→行业×年份→企业×年份 → x 被吸收。

### Q6. 你的"完整案例删除"前后的样本是否一致？
- 为什么：完整案例删除是清洗规则的最后一步，常常悄悄缩水。
- 怎么答：能讲清楚"删除前后 N 分别是 ……"。
- 失败模式：删了 50% 的样本只为了跑完整案例 → 结果靠一小撮。

## Step 6 · 控制变量放在后面，不放在前面

### Q1. 这一组控制变量的经济学理由是什么？是调节变量还是混淆变量？
- 为什么：答不出 = 你是在"加很多变量看哪个让结果稳"。
- 怎么答：能讲清楚"X 是混淆变量，必须控制 / Y 是调节变量，看异质性"。
- 失败模式：把调节变量当混淆变量 → 过度控制导致样本缩。

### Q2. 如果加了控制变量让结果反向，你怎么解释？是样本问题还是识别问题？
- 为什么：答不上来 = 你在做"事后挑控制变量"。
- 怎么答：能讲清楚"反向是因为样本变了 / 是因为识别问题 → 应该回 Step 5.5"。
- 失败模式：发现反向立刻不报这一组 → 等于隐藏了不一致。

### Q3. 你加控制的顺序是"低缺失 → 强含义 → 完整"吗？每一层加完你都审计样本缩了多少吗？
- 为什么：没审计 = 你没法解释"为什么加这层之后结果变了"。
- 怎么答：能列出每层加完后 N 和 coef 的变化。
- 失败模式：把"完整控制"那一层的结果当主规格，前面三层根本不提。

### Q4. 你的控制变量有没有"事后挑"过的痕迹？
- 为什么：事后挑 = 5 个里面挑 2 个控制。
- 怎么答：能讲清楚"我列了 8 个候选，控制了 5 个，理由是 …… 剩下 3 个是 ……"。
- 失败模式：跑了 10 个变量，挑了"让结果稳"的 3 个放进正文。

### Q5. 你的控制变量集是不是与识别策略一致？
- 为什么：DID / RD / IV 对控制变量的要求不同。
- 怎么答：能讲清楚"我的 DID 关心的是平行趋势，所以控制了 …… "。
- 失败模式：DID 加了"处理后的中介变量" → 等于自己吸收自己的识别。

### Q6. 这一步是不是已经做完"控制变量的稳健性表"？
- 为什么：稳健性表 = 解释加控制带来变化的弹药。
- 怎么答：能列出"基础 / +个体特征 / +经济特征 / +区域特征"四组结果。
- 失败模式：只有最后一组（完整控制）进正文，前几组根本不提。

## Step 7 · 当前指标失败后，才考虑替代指标

### Q1. 这个替代指标和原指标在文献里通常怎么区分？
- 为什么：不知道 = 你在"凭空造新指标"，这是 v2.0.0 硬边界明确禁止的。
- 怎么答：能讲清楚"应计 vs 实缴 / 总资产 vs 净资产 / 流量 vs 存量"。
- 失败模式：用一个看起来相关但其实不同的指标当"代理"，但代理关系没说清。

### Q2. 如果你做了替代指标，需要在正文里专门讨论"为什么放弃原指标"吗？
- 为什么：不讨论 = 审稿人会问"是不是因为原指标不显著才换的"。
- 怎么答：能讲清楚"我在正文 X 节专门写了'原指标的局限'段"。
- 失败模式：偷偷换指标，不给原因。

### Q3. 这一步是不是真的"原指标合理变换都失败"之后才进入？
- 为什么：不是 = 顺序错了，你跳过了中间轮次。
- 怎么答：能讲清楚"原指标做了 log / asinh / winsor / 比例后都不显著"。
- 失败模式：原指标可能显著但你没耐心等结果，直接换指标。

### Q4. 这个替代指标的成本 / 收益比是多少？
- 为什么：替代指标通常失去原指标的可比性。
- 怎么答：能讲清楚"替代指标让我能多获得 X 信息，但失去 Y 可比性"。
- 失败模式：换来换去，最后不知道哪个是"主规格"。

### Q5. 这个替代指标是否需要用户 / 老师确认？
- 为什么：替代指标 = 改研究问题，需要外部确认。
- 怎么答：能讲清楚"我先在沟通记录里写明替代指标理由，等用户回话再继续"。
- 失败模式：自创指标没确认就当主规格用 → 老师发现后退稿。

### Q6. 替代指标的"防御性论证"准备好了吗？
- 为什么：审稿人一定会问"为什么不是原指标"。
- 怎么答：能讲清楚"我的论证是 …… 文献支持是 …… 数据限制是 ……"。
- 失败模式：到了审稿阶段才发现自己没准备好这套论证。

## Step 8 · 最终输出与停机

### Q1. 你推荐的规格是"最显著"还是"最能辩护"？
- 为什么：默认前者 = 已经在 p-hacking 的最后一步。
- 怎么答：能讲清楚"我推荐这个规格是因为它是 X / Y / Z，不是因为它最显著"。
- 失败模式：跑了一圈后挑最显著的当推荐 → 等于把 p-hacking 摆上桌面。

### Q2. 如果审稿人质疑"你为什么不是用那条更显著的规格"，你能怎么回答？
- 为什么：答不上来 = 你没准备好辩护你推荐的规格。
- 怎么答：能讲清楚"那条规格的 X / Y / Z 让它不稳健，所以不采用"。
- 失败模式：审稿人问的时候才发现自己没想清楚 → 被动。

### Q3. 停机是基于"已经够了"还是"已经累了"？
- 为什么：后者 = 不是停机，是放弃。
- 怎么答：能讲清楚"我已经覆盖了识别 / 样本 / 模型 / 控制四个维度，没有新的调参空间了"。
- 失败模式：跑到一半放弃，留下不完整的结果。

### Q4. 这一步的产物是不是已经能回答"五个问题"？
- 为什么：v2.0.0 硬规定每个规格都要能回答 5 个问题。
- 怎么答：能列出"试了什么 / 为什么试 / 为什么停 / 正文为什么选这条 / 哪些结果虽然显著但不能用"。
- 失败模式：规格搜索做完了，但 5 个问题答不全。

### Q5. 你有没有把"失败的规格"完整保留？
- 为什么：失败留痕 = 经验研究的核心证据。
- 怎么答：能讲清楚"失败规格都在 output/审计/ 里，没删除"。
- 失败模式：失败规格只留在自己脑子里 / 已删除 → 审稿人问"你怎么知道这些"。

### Q6. 你有没有把"为什么是它不是别的"的论证写下来？
- 为什么：这是被审稿人质疑时的核心防御。
- 怎么答：能讲清楚"我在 spec-log 第 X 行写了为什么这条优先"。
- 失败模式：到了答辩阶段才发现"自己其实没想清楚"。

## 跨 Step 通用问题

### G1. 这一步是不是在按"先 …… 后 ……"的顺序？
- 为什么：顺序错了 = 之后每一步都会被怀疑。
- 怎么答：能列出当前的步骤顺序，并解释"为什么是这个顺序"。
- 失败模式：Step 5 做完了才发现 Step 3 没做 → 全部规格要返工。

### G2. 这一步跑出来的结果是不是会让前一步的结论失效？
- 为什么：会 = 顺序错了，应该回上一步。
- 怎么答：能讲清楚"这一步的结论与上一步兼容 / 不兼容"。
- 失败模式：跑完一长串发现某一步让前面的所有结论都不可信。

### G3. 这一步的产物是不是"用户能复现"的？
- 为什么：可复现 = 经验研究的最低要求。
- 怎么答：能讲清楚".do 文件路径 / 中间数据路径 / 终表路径"。
- 失败模式：结果靠临时命令跑出来，没留 .do。

### G4. 这一步的错误 / 警告是不是已经被处理？
- 为什么：未处理错误 = 后续会被埋雷。
- 怎么答：能列出"本步触发了 0 个错误 / X 个警告，全部已处理"。
- 失败模式：Stata 警告一直忽略，到主表才发现 bug。

### G5. 这一步有没有对照"v2.0.0 硬边界"自检？
- 为什么：硬边界是底线。
- 怎么答：能列出"本步未触犯任何硬边界"。
- 失败模式：跑了一圈发现触犯了硬边界 → 全部归档。
